##  Sobre o Projeto

Este projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC) do Ensino Médio integrado ao Técnico.

A plataforma web tem como objetivo auxiliar usuários na introdução ao nossos serviços e missões durante o processo.

> **Observação:** Este projeto possui caráter educacional e não substitui o acompanhamento de profissionais da saúde.

##  Como Executar

### Pré-requisitos

* [WampServer](https://www.wampserver.com/) instalado;
* Visual Studio Code ou outro editor de código de sua preferência.

### Instalação

1. Instale e execute o **WampServer**.
2. Certifique-se de que os serviços **Apache** e **MySQL** estejam ativos.
3. Coloque os arquivos do projeto dentro da pasta `www` do WampServer.
4. Abra a pasta do projeto no **Visual Studio Code**.
5. Inicie o projeto utilizando o ambiente de servidor local do WampServer.

### Acesso

Com o WampServer em execução, acesse o projeto pelo navegador através do endereço:

```text
http://localhost/telainicial.html
```

> **Observação:** importe o arquivo `.sql` disponibilizado no repositório para o MySQL através do phpMyAdmin.
